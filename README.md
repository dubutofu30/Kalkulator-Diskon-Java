# Kalkulator Diskon

## 📌 Deskripsi

Kalkulator Diskon adalah aplikasi sederhana berbasis **Java** yang digunakan untuk mengelola data pelanggan dan barang serta menghitung total pembelian setelah mendapatkan diskon.

Program ini menerima data pelanggan, data barang, jumlah pembelian, harga barang, dan persentase diskon. Selanjutnya, sistem menghitung subtotal, nilai diskon, dan total harga yang harus dibayar.

Project ini dibuat menggunakan konsep dasar **Object-Oriented Programming (OOP)** dalam Java, dengan beberapa class yang saling berhubungan untuk mengelola data pelanggan dan barang.

## 🛠️ Teknologi

- **Java**
- **NetBeans IDE**
- **Object-Oriented Programming (OOP)**
- **ArrayList**
- **Scanner** untuk input data pengguna

## ⚙️ Cara Kerja Sistem

Alur program secara sederhana:

**Input Data Pelanggan → Input Data Barang → Perhitungan Harga → Perhitungan Diskon → Menampilkan Total Pembelian**

Pengguna akan diminta memasukkan:

- Nama pelanggan
- ID pelanggan
- Nama barang
- Jumlah barang
- Harga barang
- Persentase diskon

Setelah seluruh data dimasukkan, sistem akan melakukan perhitungan secara otomatis.

## 📊 Output

Program menghasilkan informasi pembelian berupa:

- Data pelanggan
- Daftar barang yang dibeli
- Jumlah barang
- Harga barang
- Diskon
- Subtotal
- Total diskon
- Total harga setelah diskon

Contoh hasil:

```text
